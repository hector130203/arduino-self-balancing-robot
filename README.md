# Two-Wheeled Self-Balancing Robot

A closed-loop control system for a two-wheeled self-balancing robot using inertial measurement sensors (IMU) and dynamic PID control.

## 🚀 Key Features
- **Sensor Fusion:** IMU (MPU6050) integration for real-time tilt angle estimation.
- **Closed-Loop Control:** PID control algorithm for dynamic motor speed adjustment and stabilization.
- **Hardware Integration:** Microcontroller driver execution with DC motors and encoders.

## 🛠️ Built With
- **Hardware:** Microcontroller (Arduino / ESP32), MPU6050 IMU, L298N/DRV8825 Motor Driver, DC Motors.
- **Software:** Embedded C++, Control System Design.
